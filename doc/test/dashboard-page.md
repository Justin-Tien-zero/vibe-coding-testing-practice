## [x] 【前端元素】渲染儀表板基本元素（標題、歡迎訊息與登出按鈕）
**範例輸入**：掛載 DashboardPage 元件
**期待輸出**：畫面顯示「儀表板」標題、歡迎使用者的文字，以及「登出」按鈕

---

## [x] 【狀態與權限】使用者為 admin 角色時顯示「管理後台」連結
**範例輸入**：以 admin 角色登入並造訪頁面
**期待輸出**：畫面上顯示導向 `/admin` 的「🛠️ 管理後台」連結與「管理員」角色徽章

---

## [x] 【狀態與權限】使用者為非 admin 角色時隱藏「管理後台」連結
**範例輸入**：以 user 角色登入並造訪頁面
**期待輸出**：畫面上不顯示「🛠️ 管理後台」連結，且顯示「一般用戶」角色徽章

---

## [x] 【Mock API】組件掛載時顯示載入中狀態並發起商品資料請求
**範例輸入**：造訪 Dashboard 頁面（API 請求尚未回應）
**期待輸出**：畫面顯示載入動畫與「載入商品中...」文字，且呼叫 `productApi.getProducts()`

---

## [x] 【Mock API】商品資料請求成功時渲染商品列表
**範例輸入**：API 請求成功，回傳多筆商品資料
**期待輸出**：畫面正確渲染出商品名稱與價格等資訊，且不顯示載入中或錯誤訊息

---

## [x] 【Mock API】商品資料請求失敗且非 401 時顯示錯誤訊息
**範例輸入**：API 請求失敗，回傳狀態碼 500 與錯誤訊息「伺服器異常」
**期待輸出**：畫面顯示該錯誤訊息「伺服器異常」，且載入狀態解除

---

## [x] 【Mock API】商品資料請求回傳 401 時不顯示錯誤由攔截器處理
**範例輸入**：API 請求失敗，回傳 401 未授權錯誤
**期待輸出**：元件不會設定 error 狀態，不顯示畫面上的錯誤訊息區塊（交由攔截器發送登出事件）

---

## [x] 【function 邏輯】點擊登出按鈕時觸發登出邏輯並導向登入頁
**範例輸入**：點擊「登出」按鈕
**期待輸出**：呼叫 `logout()`，並以 `replace` 方式導向至 `/login` 且清除 state
