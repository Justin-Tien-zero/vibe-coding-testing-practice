> 狀態：初始為 [ ]、完成為 [x]
> 注意：狀態只能在測試通過後由流程更新。
> 測試類型：前端元素、function 邏輯

---

## [x] 【前端元素】渲染管理後台基本元素（標題、返回按鈕與說明文字）
**範例輸入**：掛載 AdminPage 元件
**期待輸出**：畫面顯示「管理後台」標題、返回 Dashboard 的連結以及「管理員專屬頁面」區塊

---

## [x] 【前端元素】根據使用者角色顯示對應徽章文字
**範例輸入**：以 admin 角色登入並造訪頁面
**期待輸出**：畫面右上角顯示「管理員」的徽章文字

---

## [x] 【前端元素】當非 admin 角色時顯示一般用戶徽章
**範例輸入**：以非 admin 角色登入並造訪頁面（純元件渲染測試，忽略路由守衛）
**期待輸出**：畫面右上角顯示「一般用戶」的徽章文字

---

## [x] 【function 邏輯】點擊登出按鈕時觸發登出邏輯並導向登入頁
**範例輸入**：點擊「登出」按鈕
**期待輸出**：呼叫 `logout()`，並以 `replace` 方式導向至 `/login` 且清除 state
